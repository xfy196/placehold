Placehold

Placeholder images, by URL.

Simple, fast, and free. Specify size, colors, format, and text — get an image instantly.

See how it works

How it works

Compose a path. Open it. That’s the image.

your.host /600x400 /1a1a1a /f7f5f2 .png ?text=Hello
  • Size
  • Background
  • Text color
  • Format
  • Custom text

Size

Use width×height, or a single number for a square. Min 10×10, max 4000×4000.

/600x400
/600

Colors

Append background and text colors as hex without #.

/600x400/dfdfdf/000000
/600x400/e85d04/ffffff
/600x400/1a1a1a/f7f5f2

Format

SVG, PNG, JPEG, GIF, and WebP — as a path segment or file extension. Combine with colors.

/600x400/png
/600x400.webp
/600x400/000000/ffffff/png

Custom text

Override the default size label with ?text=. Use + for spaces.

/600x400?text=Hello+World
/800x200/eeeeee/222222.png?text=Banner

Min 10×10 · Max 4000×4000 · SVG / PNG / JPEG / GIF / WebP
